# PvZF - Main Menu Flowers Easter Egg

This Plants vs Zombies Fusion mod brings back the interactive flowers in the main menu, just like in PvZ1.

## Installation

1. Install [MelonLoader](https://melonwiki.xyz/) to your game if you have not already.
    - Click 'Add Game Manually' then select the game executable
2. Extract the `.zip` file from [releases](https://github.com/darkthemer/PvZF_MainMenuFlowers/releases/) directly into the game directory 
    - Or move the `.dll` file in your Mods folder
